# فیلتر آلبوم

درخواست: فقط عکس‌های من و مرتب‌سازی بر اساس تاریخ و تعداد عکس. پیاده‌سازی در DTO و سرویس آلبوم، کنترل‌های Check/Select رابط، query key و کلاینت تولیدشده انجام شد. myOnly در نمای آلبوم و عکس‌های درون آن حفظ می‌شود. ترتیب جدیدترین، قدیمی‌ترین و بیشترین عکس در سرور پیش از صفحه‌بندی اجرا می‌شود. هیچ داده‌ای به‌صورت client-side برای مجوز فیلتر نمی‌شود.

بررسی: ۲۵ تست HTTP PostgreSQL موفق؛ سناریو آلبوم یک‌عکس تگ‌شده، آلبوم دو‌عکس بدون تگ، عکس تگ‌شدهٔ گروه نامرتبط و ورودی‌های نامعتبر پوشش داده شدند. TypeScript و lint فایل‌های تغییرکرده موفق‌اند. تست مرورگر در tests/album-filters.spec.ts به API واقعی توسعه متصل می‌شود.

آزمون مرورگر نیز موفق شد: فعال‌کردن checkbox و انتخاب ترتیب به API واقعی ارسال می‌شوند؛ تصاویر docs/screens/album-filters-* در ۳۹۰/۱۴۴۰ و روشن/تیره ذخیره و بازبینی شدند، بدون overflow افقی.
