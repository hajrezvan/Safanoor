# اصلاح گروه نیرو محمدجواد رضوانیان

تأیید مالک: محمدجواد رضوانیان نیروی صفا ۲۰ است؛ کمک‌مربی صفا ۲۷، مربی صفا ۳۳ و نقش مدیر فنی او حفظ می‌شوند.

برنامه: migration برای استقلال گروه عضویت اصلی از گروه کمک‌مربی، اصلاح فقط رکورد رزروشدهٔ این شخص و نقش فعال متناظر با حفظ تاریخچه، بازسازی closure و ثبت ممیزی؛ اصلاح seed همین شخص بدون تغییر سایر افراد؛ آزمون PostgreSQL برای عضویت یکتا، تاریخچه، نقش‌ها و جلوگیری از نشت دسترسی میان نقش‌های فعال. endpoint جدید نیاز نیست.

نتیجه: migration شمارهٔ ۲۹ و اصلاح فرد هدف روی دیتابیس محلی اعمال شد؛ اجرای زنجیره، migration محدودکنندهٔ ۲۸ که از قبل در مخزن و در دیتابیس معوق بود را نیز اعمال کرد. اصل الزام عضویت برای کمک‌مربی و یکتایی گروه اصلی حفظ شد؛ فقط شرط یکی‌بودن گروهِ کمک و نیرو برداشته شد. مسیرهای عمومی تخصیص نقش به افراد دیگر گسترش نیافتند.

اعتبارسنجی: TypeScript و lint فایل‌های backend تغییرکرده موفق؛ ۳۳ تست یکپارچهٔ PostgreSQL موفق (سه suite، شامل migration از صفر و seed دوبار)؛ ۴۰۴ تست can/active-role موفق. دو انتظار قدیمیِ تست person/read برای headMentor و supervisor با سیاست محدودکنندهٔ موجود هم‌تراز شدند و مجوزی به کد اضافه نشد. آزمون جدید حفظ عضویت‌ها و پیگیری، انتقال نقش فعال، تاریخچه و ممیزی، اجرای تکراری بی‌اثر، منع عضو اصلی دوم و منع کمک‌مربی بدون عضویت اصلی را بررسی می‌کند.

بازبینی مرورگر: ورود با حساب هدف، مشاهدهٔ گزینهٔ «صفا ۲۰ - نیرو» و نبود «صفا ۲۷ - نیرو»، انتخاب نقش و تأیید پاسخ واقعی /people/me موفق. تصاویر member-group-corrected-menu.png و member-group-corrected-active.png در docs/screens ذخیره شدند. سایر افراد و رمزهای آن‌ها بازنشانی نشدند؛ seed دوبار فقط در دیتابیس تست اجرا شد.
