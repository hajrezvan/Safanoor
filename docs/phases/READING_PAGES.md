# ثبت صفحه و سابقهٔ مطالعه

برنامه: تعداد صفحات روی کتاب، صفحهٔ جاری روی مطالعهٔ شخصی و رویدادهای تغییر صفحه با تاریخ سرور تهران؛ DTO و OpenAPI به‌روز؛ دکمه شروع، کنترل صفحه، تأیید پایان و chip روی جلد؛ دانلود PDF واضح و عملیات هم‌تراز پایین کارت. کتاب‌های قدیمی تعداد صفحهٔ حدسی نمی‌گیرند و مربی باید آن را تکمیل کند. تغییرات صفحات به‌صورت delta مثبت/منفی نگهداری می‌شوند تا اصلاح عقب‌گرد باعث دوباره‌شماری نشود؛ گزارش‌گیری دیگران تا تعیین مجوز مستقل اضافه نمی‌شود.

نتیجه: پیاده‌سازی و migration محلی انجام شد. DTO ساخت کتاب، تعداد صفحات را اجباری می‌کند؛ کتاب قدیمی فاقد مقدار تا تکمیل مربی کنترل شروع ندارد. OpenAPI و کلاینت تولیدشده به‌روز شدند. ۲۵ تست HTTP با PostgreSQL موفق، شامل ۲۰ صفحه دیروز و ۶۰ امروز = ۴۰ امروز، تکرار بی‌اثر، ورودی نامعتبر، تأیید پایان و منع کاهش تعداد زیر پیشرفت؛ آزمون مرورگر ثبت/تأیید/انصراف، برچسب روی جلد، مقصد PDF و هم‌ترازی دکمه‌ها موفق. تصاویر دو عرض/دو پوسته بازبینی شدند. TypeScript و lint فایل‌های تغییرکرده موفق‌اند.
