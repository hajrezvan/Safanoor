# درخواست‌های بعد از تغییرات تصویری — تکمیل شد

مواردی که هنگام درخواست اولیهٔ کامیت ناتمام بودند، در بازیابی گفتگو تکمیل شدند:

- نمودارهای داشبورد: ستون‌های چندرنگ، زمینهٔ نرم، اعداد فارسی در محور/برچسب/tooltip؛ عرض مستقل محور مالی از بریدن متن جلوگیری می‌کند. رسم بدون انیمیشن ورودی طولانی، تا نمودارهای خارج از viewport ناقص نمانند و reduced-motion رعایت شود.
- گفت‌وگوهای اخیر: حالت avatarsOnly علت نمایش صرف آواتار/زمان بود؛ اکنون عنوان و پیش‌نمایش مجاز API همراه زمان نمایش داده می‌شوند. گفت‌وگوی بی‌پیام در فهرست نیست و حالت خالی واقعی حفظ شده است.
- نیرو بخش اردویی را نمی‌بیند: can نقش فعال member را رد می‌کند؛ policy read عمومی sameGroup به campStaff محدود شد. capability سرور viewCamps تمام ورودی‌های سایدبار، خانه و برنامه‌ها را کنترل می‌کند؛ مسیر مستقیم UI حالت عدم دسترسی و API پاسخ 403 دارد. دسترسی مربی/کمک‌مربی حفظ شده و فهرست به گروه نقش فعال محدود است.
- کارت‌های گروه من و حریم خصوصی خانه: پنل‌های سبز/یاسی، تیتر و آیکون روشن و هماهنگ با تم تیره و روشن، بدون تغییر داده و متن حریم خصوصی.

جزئیات بررسی تمام درخواست‌های چت و اعتبارسنجی در CHAT_RECOVERY.md ثبت شده است.
