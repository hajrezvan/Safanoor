# گزارش بررسی فاز اول

تاریخ: ۲۵ مهر ۱۴۰۵ (۲۰۲۶/۱۰/۱۷). داده‌های بررسی کاملاً مصنوعی‌اند.

| بررسی | نتیجه |
|---|---|
| TypeScript strict، shared و هر دو برنامه | موفق |
| lint هر دو برنامه | موفق |
| تست بستهٔ مشترک: تاریخ جلالی، سن، کد ملی، نرمال‌سازی | ۴ موفق |
| تست واحد backend، شامل ماتریس ۲۶ منبع × ۱۰ رابطه | ۲۷۴ موفق |
| تست HTTP یکپارچه با PostgreSQL واقعی | ۲۰ موفق |
| قرارداد طراحی، کنتراست، ذخیرهٔ توکن و cache آفلاین | ۴ موفق |
| Playwright: نشست، مسیرها، طراحی و حالت آفلاین | ۳ موفق |
| migration از صفر و seed دوبار | موفق؛ در تست و Compose |
| بازتولید OpenAPI و کلاینت بدون تغییر hash | موفق |
| build تولیدی Next.js و پاسخ ۴۰۴ صفحهٔ توسعه | موفق |
| worker واقعی pg-boss: بررسی، تأیید، ثبت و تکرار بی‌اثر | موفق؛ روی میزبان و داخل Docker |
| تصویر Docker بک‌اند و اجرای API | موفق |
| تصویر Docker رابط با نصب frozen و build تولیدی | موفق |
| کل Compose پشت nginx روی ۸۰۸۰ | موفق؛ health، ورود کوکی امن، صفحهٔ مدیریت محافظت‌شده، RTL و منع صفحهٔ توسعه |
| نقش runtime پایگاه داده | فاقد superuser و BYPASSRLS |
| تصویر S3Proxy، bucket خصوصی و آداپتور واقعی S3 | موفق؛ نوشتن، خواندن، URL امضاشده و رد خواندن ناشناس |

جمع تست‌های ثبت‌شده در runnerها: ۳۰۵ تست موفق. smokeهای runtime علاوه بر این تعدادند.

۵۲ تصویر در `docs/screens/`: ۱۳ صفحه × دو عرض ۳۹۰/۱۴۴۰ × دو پوستهٔ روشن/تیره. تصاویر از نظر چیدمان، RTL، گوشه‌های گرد، متن بیرون‌زده و کنتراست بازبینی شدند. تست مرورگر overflow افقی صفحه و خطاهای console/runtime را رد می‌کند. جدول مدیریت در موبایل داخل ظرف خودش افقی می‌لغزد.

مسیرهای بررسی: ورود، خانه، پروفایل، رضایت، اعلان‌ها، نمای کلی مدیریت، افراد، گروه‌ها، ورود گروهی، ارجاع/سیاست، audit، تنظیمات و راهنمای طراحی. فرم‌های عملیاتی از API واقعی استفاده می‌کنند.

CI در `.gitlab-ci.yml` تعریف شده است؛ اجرای موفق pipeline روی runner ریموت هنوز تأیید نشده است.
