# گزارش بازطراحی پنل Staff / دانش‌آموز

شِل ادمین‌مانند مشترک برای ادمین/مربی/کمک‌مربی (`StaffShell` + سایدبار)، bottom navigation دانش‌آموز، و دامنهٔ یادگیری جدید (اطلاعیه، سرفصل کتاب/دوره، آزمون تشریحی، صوت/PDF/آپارات، پیشرفت درس) پیاده‌سازی شد.

مسیرهای اصلی: `/staff/*`، `/student`، `/student/school`، `/student/library`، `/student/messenger`، `/student/profile`.
