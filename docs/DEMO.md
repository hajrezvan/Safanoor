# دادهٔ ارائهٔ صفانور

داده‌ها کاملاً مصنوعی و مربوط به امکانات فاز اول‌اند. برای ساخت یا تکمیل دوباره:

```sh
docker compose run --rm -e NODE_ENV=development backend node dist/seed-demo.js
```

بدون Docker: `npm --prefix api run seed:demo`. رمز همهٔ حساب‌های اولیه `SafanoorDemo#1405` است؛ این دستور رمزِ ویرایش‌شده را بازنشانی نمی‌کند.

| نقش | شمارهٔ ورود | آنچه می‌توان دید |
|---|---|---|
| مدیر فنی | +989100000040 | اعضا، تأییدهای متفاوت هویت، گروه‌ها، سه حالت ورود گروهی، audit |
| مربی رویش | +989100000003 | اعضای رویش، واگذاری پیگیری، ورود گروهیِ خودش و ارجاع‌های صادرشده |
| مربی باران | +989100000004 | اعضا و ورود گروهی مستقل از گروه رویش |
| کمک‌مربی‌ها | +989100000005، +989100000006، +989100000007 | پروفایل، عضویت و اعلان‌های مرتبط با نقش |
| نیروها | +989100000011 تا +989100000022 | پروفایل و تاریخ جلالی متنوع، گروه، رضایت و اعلان‌های خوانده/نخوانده |
| والدها | +989100000031، +989100000032 | فقط فرزندان تأییدشده، رضایت و اعلان‌های خودشان |
| سرمربی | +989100000002 | پروفایل، عضویت و اعلان‌های مخصوص حساب |
| ناظر | +989100000001 | پروفایل، اعلان‌ها و ارجاع‌های دریافتی در `/admin/access` |

حساب +989100000015 عمداً در انتظار رضایت والد باقی می‌ماند تا این جریان هم قابل ارائه باشد. مادرِ تأییدشدهٔ او حساب +989100000032 است.

برای هر یک از ۲۲ حساب، پنج اعلان تازه با زمان و وضعیت خواندن متفاوت، افزون بر پیام خوش‌آمدگویی وجود دارد. ۹ job نمونه برای مدیر و دو مربی، سه ارجاع و تاریخچهٔ metadata ممیزی اضافه می‌شود. پیش‌نمایش‌های ورودی رمز‌شده‌اند؛ وضعیت «آماده» را می‌توان واقعاً تأیید کرد تا worker دو عضو جدید بسازد. حساب ورودِ اعضای واردشده طبق روند عادی توسط مدیر ایجاد می‌شود.

دستور فقط شناسه‌های رزروشدهٔ نمونه را تکمیل می‌کند. پروفایل ویرایش‌شده، پیام خوانده‌شده، ارجاع لغوشده، نتیجهٔ import، تاریخچهٔ رضایت، رمز و قفل حساب را بازنشانی نمی‌کند. اجرای آن در production رد می‌شود و برای سازمان دارای دادهٔ واقعی، حساب‌های نمونه را خودکار ایجاد نمی‌کند.

## بررسی انجام‌شده

۲۷۴ تست واحد، ۲۵ تست یکپارچهٔ PostgreSQL و تست‌های مشترک/قرارداد طراحی پاس شدند. تست‌های تازه پوشش همهٔ حساب‌ها، حفظ رمز و رضایت، اجرای واقعی import آماده، محدودیت مشاهدهٔ پیش‌نمایش و ارجاع، ممنوعیت production و بی‌اثر بودن اجرای تکراری را بررسی می‌کنند. ۳۲ تصویر از پنج نقش، در دو عرض و دو پوسته، در `docs/screens/demo-*` ثبت و بازبینی شدند.

انتخاب فایل ورودی با دکمهٔ فارسی و گرد انجام می‌شود؛ انتخاب فایل با صفحه‌کلید و فعال‌شدن فرم پس از انتخاب فایل/گروه نیز در مرورگر بررسی شد.
