# درخواست‌های بعد از تغییرات تصویری

این موارد هنگام درخواست «کامیت کن» هنوز پیاده نشده‌اند:

- رنگ‌بندی جذاب نمودارهای داشبورد و فارسی بودن تمام اعداد محور، راهنما و tooltip.
- بررسی پیش‌نمایش گفت‌وگوهای اخیر که فقط آواتار/زمان نشان می‌دهد؛ نمایش عنوان/محتوای مجاز یا حالت خالی واقعی.
- طبق دستور مالک، نقش نیرو بخش اردویی را نبیند؛ نیازمند سیاست مرکزی backend، capability برگشتی API و پنهان‌کردن تمام ورودی‌های sidebar، میان‌بر خانه و برنامه‌ها و آزمون منع دسترسی مستقیم است.
- رنگ‌بندی کارت‌های گروه من و حریم خصوصی خانه با حفظ ظاهر مناسب مخاطب بزرگسال.
