# ویدیوهای معرفی نقش‌های صفانور

این پوشه شامل هفت ویدیوی مستقل و کم‌حجم برای ارائهٔ فاز اول است:

1. مدیر فنی
2. ناظر
3. سرمربی
4. مربی — نسخهٔ کامل و مرحله‌به‌مرحلهٔ قابلیت‌های فاز اول
5. کمک‌مربی
6. نیرو
7. والد

همهٔ فایل‌ها MP4 با وضوح 720p و کدک H.264 هستند و برای ارسال در پیام‌رسان بهینه شده‌اند. ویدیوها بدون صدا تهیه شده‌اند تا بتوان روی آن‌ها هنگام ارائه توضیح داد یا بعداً گویندگی افزود.

ویدیوی مربی علاوه بر معرفی صفحات، عملیات واقعی افزودن و ویرایش عضو، تأیید هویت، محدودیت غیرفعال‌سازی، واگذاری پیگیری، ورود گروهی، لغو ارجاع و خواندن اعلان را روی پایگاه‌دادهٔ موقت نمایش می‌دهد.

برای بازتولید ویدیوها در زمانی که سامانه روی پورت ۸۰۸۰ اجراست:

```sh
node scripts/record-demo-videos.mjs
```
