# Seed سلسله‌مراتب واقعی (فقط توسعهٔ محلی)

اسکریپت `npm --prefix api run seed:hierarchy` افراد و گروه‌های صفا را از فهرست سازمانی برای تست محلی می‌سازد. در `NODE_ENV=production` اجرا نمی‌شود. شماره‌ها ساختگی‌اند؛ رمز مشترک با seed نمایشی است.

## اجرا

```sh
# در صورت نیاز ابتدا seed پایه (رضایت و سیاست‌ها)
npm --prefix api run seed

# سلسله‌مراتب واقعی — تکرارپذیر
npm --prefix api run seed:hierarchy

# دادهٔ آزمایشی دامنه (مشاوره، جلسه، اردو، مالی، آلبوم، مراودات، …)
npm --prefix api run seed:hierarchy-demo

# همان داده + گروه‌های خواهر / ارجاع / import / admin برای ارائه
# (و آپلود رمزشده به S3 محلی وقتی STORAGE_DRIVER=s3)
node ../scripts/ensure-minio.mjs
npm --prefix api run seed:demo-session
```

`seed:hierarchy-demo` / `seed:demo-session` برای افراد سلسله‌مراتب، جداول دامنه را با UUIDهای `70000000-…` پر می‌کنند و عکس‌های `api/seed-assets/album/` را در آلبوم صفا ۲۷ (و پیوست جزئی به صفا ۲۰) می‌گذارند؛ با `STORAGE_DRIVER=s3` بایت‌ها روی MinIO/S3Proxy (`127.0.0.1:9000`) ذخیره می‌شوند.

**کلاس‌ها / کتابخانه:** ردیف‌های `study_path` و `study_path_item` برای صفا ۲۷ (و یک مسیر برای صفا ۲۰) seed می‌شوند. صفحهٔ `/classes` و `/library` هر دو از `GET /api/v1/groups/{id}/study-paths` می‌خوانند؛ ضبط صوتی LMS هنوز در v1 نیست.

شناسه‌های UUID با پیشوند `40000000` (افراد)، `50000000` (گروه‌ها)، `60000000` (کاربران) رزرو شده‌اند. اجرای دوباره مالک گروه، عضویت‌ها، `org_level` و `password_hash` (به `DEMO_PASSWORD`) را هم‌تراز می‌کند.

## قواعد نگاشت

| ستون فهرست | رفتار در سامانه |
|---|---|
| ناظر | اگر گروه والد (کمک‌مربی/نیرو) در seed وجود نداشته باشد → `supervisor` بدون عضویت. اگر هم مربی باشد و گروه والد موجود باشد → `mentor` می‌ماند و نظارت بر صفاِ ناظر از طریق سلسله‌مراتب (`person_ancestors`) است |
| مربی | مالک گروه (نفر اول برای هر صفا؛ در تعارض صفا ۳۳/۳۴ نفر اول فهرست برنده است) |
| کمک مربی | عضویت همزمان `member` + `assistant` همان گروه |
| نیرو | اگر کمک‌مربی خالی باشد، عضویت `member` همان گروه |

گروه‌های صفا ۷ / ۱۴ / ۱۵ فقط در ردیف ناظرها آمده‌اند و ساخته نمی‌شوند. گروه‌های ساخته‌شده: **صفا ۲۰، ۲۷، ۳۳، ۳۴**.

مالکان و نقش دوگانه:

| گروه | مالک | نقش عملی |
|---|---|---|
| صفا ۲۰ | مهدی رضوانیان | ناظر خالص (بدون گروه والد) → `supervisor`؛ ناظر صفا ۲۷ |
| صفا ۲۷ | محمد گودرزی | مربی صفا ۲۷ + عضو/کمک صفا ۲۰؛ ناظر صفا ۳۴ از طریق زنجیره |
| صفا ۳۳ | محمدجواد رضوانیان | مربی |
| صفا ۳۴ | محمدحسین امینی | مربی (عضو صفا ۲۷) |

## رمز و تلفن‌ها

- رمز همه: `12345678`
- تلفن/ورود: `+98912` + هفت رقم شمارنده (`+989120000001` … `+989120000039`)

### نمونه‌های ورود

| نقش | نام | ورود |
|---|---|---|
| ناظر (مالک صفا ۲۰) | مهدی رضوانیان | `+989120000001` |
| مربی صفا ۲۷ (ناظر صفا ۳۴) | محمد گودرزی | `+989120000037` |
| مربی (مالک صفا ۳۴) | محمدحسین امینی | `+989120000002` |
| مربی (مالک صفا ۳۳) + مدیر فنی | محمدجواد رضوانیان | `+989120000012` |

محمدجواد (`is_admin`) علاوه بر نقش‌های سازمانی (مربی صفا ۳۳، کمک‌مربی/نیرو صفا ۲۷) نقش **مدیر فنی** را در تعویض‌گر نقش سایدبار دارد؛ تنظیمات فنی (`/admin/settings`) فقط با نقش فعال مدیر فنی دیده می‌شود.
| مربی (بدون مالکیت؛ کمک‌مربی صفا ۲۰) | حمید جعفری | `+989120000038` |
| کمک‌مربی صفا ۲۷ | مصطفی بهبهانی | `+989120000003` |
| نیرو صفا ۲۰ | مصطفی حسن‌زاده | `+989120000006` |

فهرست کامل در خروجی اجرای اسکریپت و آرایهٔ `HIERARCHY_ROSTER` داخل `api/src/seed-hierarchy.ts` است.
