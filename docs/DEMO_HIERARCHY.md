# سلسله‌مراتب اولیهٔ دادهٔ نمایشی

این جدول دادهٔ اولیهٔ سلسله‌مراتب برای محیط demo است (فهرست سازمانی گروه‌های صفا). نام‌ها همان‌طور که در منبع آمده‌اند نگه‌داری شده‌اند (گاهی نام‌خانوادگی اول، گاهی نام کوچک). برای ساخت حساب‌ها در توسعهٔ محلی: `npm --prefix api run seed:hierarchy` — جزئیات در [REAL_HIERARCHY_SEED.md](./REAL_HIERARCHY_SEED.md).

## Seed کامل ارائه (داشبورد زنده)

برای پر کردن دامنه‌های موجود در اپ (مشاوره، اردو، مالی رویداد، جلسه، LMS، کتابخانه، آلبوم، مراودات، اعلان، ارجاع، import، …) و ذخیرهٔ فایل‌ها در S3 محلی:

```sh
# Postgres + object storage (اگر بالا نیستند)
docker start safanoor-postgres 2>/dev/null || true
node scripts/ensure-minio.mjs

npm --prefix api run seed:hierarchy          # افراد و گروه‌ها
npm --prefix api run seed:demo-session      # دادهٔ غنی + S3 (idempotent)
```

رمز همه: `12345678`. ورودهای اصلی ارائه:

| نام | ورود | نقش |
|---|---|---|
| مهدی رضوانیان | `+989120000001` / `09120000001` | ناظر / مالک صفا ۲۰ |
| محمد گودرزی | `+989120000037` | مربی صفا ۲۷ |
| محمدجواد رضوانیان | `+989120000012` | مربی صفا ۳۳ (+ `is_admin` در demo-session) |
| مصطفی بهبهانی | `+989120000003` | کمک‌مربی صفا ۲۷ |
| مهدی سیف‌الهی | `+989120000016` | نیرو صفا ۲۰ |

`seed:demo-session` همان `seed-hierarchy-demo` را با پر کردن گروه‌های خواهر، اردوی مشترک، reading، grant، import، آواتار پنج نفر ارائه، جزئیات اردو (اطلاعیه/برنامه/مجوز)، تگ عکس، LMS صفا ۲۰ و مالی صفا ۳۳ اجرا می‌کند و با `STORAGE_DRIVER=s3` بایت‌ها را از طریق `EncryptedStorageAdapter` روی `127.0.0.1:9000` می‌نویسد.

**اسکیمای فعلی (تأییدشده روی migrations/DB):** جداول `busy_block`، `rsvp`، `attendance`، `wallet`، `ledger_entry`، `project`، `task` هنوز migrate نشده‌اند. معادل‌های UI موجود: مالی = `program_event` + `cost_item`؛ زمان‌بندی = `camp` / `camp_schedule_item` / `meeting`. `parent_link` خالی می‌ماند چون در فهرست سلسله‌مراتب کسی زیر ۱۸ نیست.
